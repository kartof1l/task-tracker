# История диалогов с LLM

## Сессия: реализация периодичности задач

### Запрос 1: анализ кодовой базы
Скинул ссылку на репозиторий, попросил посмотреть структуру и архитектуру проекта. LLM описал слои (domain → repository → usecase → handler) и подсветил ключевые файлы, которые затронут изменения.

### Запрос 2: проектирование БД
Предложил набор колонок для хранения периодичности: recurrence_type, recurrence_interval, recurrence_days, recurrence_dates, recurrence_parity, recurrence_start, recurrence_end. LLM подтвердил структуру, обсудили типы — INT[] для чисел месяца, DATE[] для дат, TEXT для parity. Решил использовать указатели для nullable-полей, LLM объяснил как это работает с omitempty в JSON.

### Запрос 3: миграция
Написал структуру ALTER TABLE, попросил LLM привести к правильному синтаксису и оформить down-файл. LLM поправил форматирование, сгенерировал оба файла миграции.

### Запрос 4: модель Task
Спроектировал структуру с новыми полями, отправил на проверку. LLM поправил json-теги на snake_case, напомнил про экспортируемые имена. Обсудили нюанс с []time.Time против []string для DATE[] — решили использовать строки, чтобы избежать кастомного сканера для pgx, для тестового задания избыточно.

### Запрос 5: валидация
Реализовал Valid() для RecurrenceType и ValidateRecurrence() с проверкой сочетания полей для каждого типа периодичности. Попросил LLM перевести ошибки на русский и проверить полноту проверок. LLM подтвердил логику, помог с формулировками.

### Запрос 6: репозиторий
Обновил все SQL-запросы и scanTask под новые поля. Скинул код на ревью — LLM нашёл расхождение в порядке аргументов в Update (перепутал CreatedAt и UpdatedAt местами). Поправил.

### Запрос 7: сервисный слой
Добавил поля в CreateInput/UpdateInput, обновил service.go. Уточнил у LLM насчёт порядка валидации — стоит ли вызывать ValidateRecurrence до установки временных меток. Решили, что логически правильнее сразу после заполнения модели.

### Запрос 8: handler'ы и DTO
Обновил DTO-структуры и маппинг в newTaskDTO. LLM проверил соответствие полей между слоями — расхождений не нашёл.

### Запрос 9: swagger
Обновил openapi.json, добавил recurrence-поля во все схемы. Попросил LLM проверить структуру и синтаксис JSON.
